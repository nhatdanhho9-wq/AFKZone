## 🗄️ DATABASE MIGRATION

### New Table: `license_devices`
```sql
CREATE TABLE license_devices (
    id SERIAL PRIMARY KEY,
    license_key VARCHAR(255) NOT NULL,
    device_id VARCHAR(255) NOT NULL,
    activated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_check TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT TRUE,
    UNIQUE(license_key, device_id)
);
```

### Updated Table: `licenses`
```sql
ALTER TABLE licenses ADD COLUMN max_devices INTEGER DEFAULT 1;

UPDATE licenses SET max_devices = 2 WHERE tier = 'basic';
UPDATE licenses SET max_devices = 5 WHERE tier = 'pro';
UPDATE licenses SET max_devices = -1 WHERE tier = 'enterprise';
```
