### API Endpoints (All Tested ✅)
**Base URL:** `https://api.afkzone.cloud`

1. **GET /** - Health check
2. **POST /activate** - License activation
3. **POST /check** - License validation (24h background check)
4. **POST /generate** - Admin bulk license generation
5. **GET /list** - Admin list licenses
6. **POST /trial/generate** - Auto-generate 7-day trial
7. **POST /trial/check** - Check if device used trial
8. **POST /payment/create** - Create ZaloPay order
9. **POST /payment/callback** - ZaloPay webhook
10. **GET /version/check** - App update check
11. **GET /health** - Database health
