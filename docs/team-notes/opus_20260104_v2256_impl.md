## New Endpoints (v2.2.56)

### POST /api/license/assign
- Assign license to device with optional alias
- Checks device slots before assignment
- Returns: success, action (assigned/updated)

### GET /api/license/{license_key}/slots
- Get device slot usage for license
- Returns: used_devices, max_devices, available_slots, devices list

### PATCH /api/license/device/{device_id}/alias
- Update device alias
- Returns: success, device_id, alias

## Renewal Logic

### Same Tier Renewal
- Extends existing license: new_expiry = max(current_expiry, now) + duration_days
- No new license created, same license_key preserved

### Different Tier
- Creates new license with new license_key
- Auto-assigns to device for backward compatibility
- Logs action as "created"
