# Team Notes - Opus ↔ Codex Collaboration

Thư mục này dùng để **Opus Team** và **Codex Team** trao đổi reports, notes, và review.

## Workflow

```
┌─────────────┐     Report      ┌─────────────┐
│  Opus Team  │ ──────────────► │ Codex Team  │
│  (Thực thi) │ ◄────────────── │  (Review)   │
└─────────────┘   Feedback      └─────────────┘
```

## File Structure

| File | Purpose |
|------|---------|
| `phase2_handoff_report.md` | Report Phase 2 → Codex review |
| `codex_feedback_*.md` | Codex team feedback |
| `opus_response_*.md` | Opus team trả lời |

## Rules

1. **Naming**: `{team}_{action}_{date}.md` (e.g., `codex_review_20260101.md`)
2. **Format**: Dùng markdown với sections rõ ràng
3. **Sign-off**: Cuối file ghi team name + timestamp
